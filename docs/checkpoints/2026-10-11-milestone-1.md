## Assumptions

- The timer is off by default for every vibe. Its controls sit in the card header because the bottom control row is already full at phone width.
- Restore always merges and never replaces. For objects and settings, the device's existing values win, and arrays are unioned.
- The backup leaves out the AI question cache (`qa-cache-v2`, which can be regenerated) and the 18+ confirmation.

## Pending decisions

1. **Names merge on restore:** `qa-names` is a two-item array, so the shared array-union merge (also used by the old-address move) can append the backup's names after the device's. The app only reads the first two, so nothing visibly breaks. Options: (a) leave as is, (b) special-case scalar-like keys so the device value wins, (c) let incoming names fill only empty slots.
2. **Timer default for Quick Fire:** should Quick Fire turn the timer on automatically? Options: (a) no, keep the current single toggle, (b) yes, Quick Fire only, (c) remember the setting per vibe.
3. **Short offline decks:** offline, the Deep Talk deck has only 12 built-in cards, so it can come up short. Options: (a) write more starter cards, (b) top up from other non-adult vibes, (c) leave as is.

## Resolved (follow-up round)

1. Names merge: fixed. `mergeKey` in `lib/transfer.ts` treats `qa-names` as a pair: names already set on the device are kept, blank slots are filled from the backup, and the list never grows. It is used by both backup restore and the old-address move.
2. Timer: now on by default for all vibes. There is a switch with a length picker on the home screen (`components/TimerRow.tsx`), and the in-play toggle is kept. Both share the `hooks/useTimerSettings.ts` hook. Checked at 360 and 1280 px.
3. Starter deck: every vibe went from 12 to 32 cards (204 total, 120 new). The deck lint passes. In review, two Quick Fire cards were replaced: one repeated an existing soup debate, and the other was weak.
